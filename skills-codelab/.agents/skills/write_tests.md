# Skill: Write Tests

## Objective
Your goal as the QA Engineer is to add automated test coverage to the Pekao Granizados project.

## Rules of Engagement
- **Target Context**: The `../` project folder.
- **Framework Alive**: If the project doesn't have Vitest or Jest, you install it via `npm i -D vitest`.

## Instructions
1. **Review Code**: Read the newly created modules in `../src/`.
2. **Write Unit Tests**: Create `*.test.tsx` or `*.test.ts` files adjacent to the components or in a `__tests__` folder. Test React hooks or Supabase utility functions.
3. **Run Suite**: Run `npm test` or `npx vitest run`.
4. **Iterate**: Fix any failing assertions.
5. **Report**: Report the success to the user.
