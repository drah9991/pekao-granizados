# Skill: Design System

## Objective
Your goal as the Designer is to establish or extend the "WOW" factor for Pekao Granizados by providing CSS/Tailwind rules for new features.

## Rules of Engagement
- **Match Existing UI**: Never propose styling that wildly contrasts with the existing `index.css` or Tailwind configuration unless authorized. You must read them first.
- **Save Location**: Save output to `production_artifacts/Design_System.md`.

## Instructions
1. **Analyze Codebase**: Review the main layout patterns, colors, and button components currently stored in `../src/components` and `../src/index.css`.
2. **Define Extension Tokens**: Detail the new design tokens:
   - **Colors**: Hex codes that extend the current palette.
   - **Gradients/Shadows**: How to apply "glassmorphism" or deep shadows to the new module.
3. **Provide Snippets**: Give the engineer specific Tailwind utility classes combinations to use for the new components to assure high visual quality.
4. Save the document.
